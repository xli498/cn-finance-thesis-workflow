# 稳健性与内生性清单

> 以下是候选方法，不是必做项目。只有研究设计、识别假设、数据结构和处理时序适用时才执行；未采用某方法时，记录排除理由。

## 稳健性（按研究设计选择，不设统一数量门槛）

- [ ] 更换被解释变量度量
- [ ] 更换固定效应组合（个体 / 年份 / 行业×年份）
- [ ] 在误差相关结构与处理变量变化层级支持时，考虑更换聚类层级（公司 / 行业 / 年份）；聚类组过少时评估小样本修正或替代推断，按年份聚类不作为默认选项
- [ ] 若采用缩尾，检查合理替代阈值或异常值处理方法
- [ ] 剔除特殊样本（IPO 当年、金融业、危机年份、特定地区）
- [ ] 仅在估计量假设适用时，考虑更换估计方法（例如 OLS / FE / GMM）
- [ ] 若有明确可检验含义，执行安慰剂 / 伪处理检验；随机化方案须符合研究设计

## 内生性

- [ ] 识别假设成立
- [ ] 滞后一期
- [ ] 工具变量（相关性 + 外生性，弱工具检验）
- [ ] PSM / PSM-DID（平衡性检验）
- [ ] DID（平行趋势检验）

## 报告

- [ ] 系数、标准误、显著性、观测数、R²
- [ ] 经济意义解释
- [ ] 确认性与探索性分析分开
