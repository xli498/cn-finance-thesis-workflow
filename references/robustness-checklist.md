# 稳健性与内生性清单

## 稳健性（至少 3 项）

- [ ] 更换被解释变量度量
- [ ] 更换固定效应组合（个体 / 年份 / 行业×年份）
- [ ] 更换聚类层级（公司 / 行业 / 年份）
- [ ] 更换缩尾比例（1% ↔ 5%）
- [ ] 剔除特殊样本（IPO 当年、金融业、危机年份、特定地区）
- [ ] 更换估计方法（OLS / FE / 系统 GMM）
- [ ] 安慰剂检验（随机化处理变量或时间）

## 内生性

- [ ] 识别假设成立
- [ ] 滞后一期
- [ ] 工具变量（相关性 + 外生性，弱工具检验）
- [ ] PSM / PSM-DID（平衡性检验）
- [ ] DID（平行趋势检验）

## 报告

- [ ] 系数、标准误、显著性、观测数、R²
- [ ] 经济意义解释
- [ ] 确认性与探索性分析分开
