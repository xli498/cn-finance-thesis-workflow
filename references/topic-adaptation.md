# 题目适配规则

本 Skill 的核心是通用的 S0–S6 论文工作流，不绑定某个题目。主题附录只能提供候选变量、文献关键词和常见识别策略，不能替代当前用户的研究设计。

## 适配顺序

1. 读取题目、研究对象、样本期、数据来源和学校/导师要求。
2. 生成一页题目卡：研究问题、X、Y、机制、控制变量、数据可得性和风险。
3. 检索同题目或相近题目的文献，记录检索式、时间和覆盖边界。
4. 检查变量定义和数据字段，不得从主题附录直接复制默认口径。
5. 只把经用户确认、数据验证和文献支持的设计写入项目。

## 主题附录的使用条件

- 题目匹配时：可加载对应附录作为候选清单。
- 题目不匹配时：不加载无关附录；使用通用模板重新设计。
- 题目不明确时：先停在 S0，列出最少必要澄清项，不假设题目。

## 多用户隐私边界

- 公开仓库中的示例不是事实数据库，也不是新用户的背景资料。
- 维护者的题目、数据、学校、联系方式、内部路径和记忆不得进入其他用户项目。
- 外部服务调用前只传完成当前任务所需的最小字段；敏感字段先脱敏或留在本地。
- 真实用户项目默认不回传到公开 GitHub；用户明确要求公开时，先做凭证、个人信息、原始数据、研究未公开内容和 Git 历史审查。
