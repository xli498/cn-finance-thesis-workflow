# 阶段质量门 Checklist

## S0 选题与可行性

- [ ] 研究问题一句话可陈述
- [ ] 解释变量 / 被解释变量 / 控制变量已列出
- [ ] 数据可得性已确认（来源 / 字段 / 期间）
- [ ] 假设可证伪

## S1 文献与假设

- [ ] 检索协议已记录（来源 / 检索式 / 时间 / 筛选）
- [ ] 文献矩阵已建（作者 / 数据 / 方法 / 结论 / 关系 / 可引点）
- [ ] 关键假设的文献依据已核验，并说明检索范围与覆盖边界
- [ ] 所有引文可核（标题 / 作者 / 年份 / DOI）

## S2 数据获取

- [ ] 来源、期间、代码口径、字段、取数时间齐全
- [ ] 变量字典完成（定义 / 来源 / 计算 / 单位）
- [ ] 原始数据只读留存
- [ ] 已记录用了哪个来源或采集代码

## S3 数据清洗

- [ ] 行业、ST 状态、上市年份等筛选已按研究设计决定，并记录纳入 / 排除理由
- [ ] B 股 H 股按设计处理
- [ ] 关键变量缺失处理已说明
- [ ] 异常值处理方式与阈值已按研究设计确定并记录（如采用缩尾）
- [ ] 面板索引、重复键、连续性与平衡度检查完成；可用 Stata、Python、R 或其他等价工具，并记录工具与结果
- [ ] 清洗日志已留痕

## S4 实证与稳健性

- [ ] 分析计划先于回归
- [ ] 基准回归 + 聚类层级说明；聚类层级符合误差相关结构，聚类组过少时已评估小样本推断风险
- [ ] 已执行与识别假设、数据结构相匹配的稳健性检验，并说明其作用（不以固定数量代替论证）
- [ ] 内生性处理与识别假设讨论
- [ ] 报告经济意义而不只统计显著

## S5 写作

- [ ] 引言含钩子 / 问题 / 发现 / 贡献 / 路线图
- [ ] 摘要最后写，并符合院校或目标期刊的字数要求
- [ ] 作者已核对关键动机、判断、数据、引用和改写内容
- [ ] 主张—证据对齐表无 missing

## S6 终稿与交付

- [ ] 引用逐条核验通过
- [ ] 文本六维度检查通过
- [ ] 参考文献格式统一
- [ ] 图表编号与交叉引用一致
- [ ] 分版本存档
