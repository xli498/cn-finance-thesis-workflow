# 阶段质量门 Checklist

## S0 选题与可行性

- [ ] 研究问题一句话可陈述
- [ ] 解释变量 / 被解释变量 / 控制变量已列出
- [ ] 数据可得性已确认（来源 / 字段 / 期间）
- [ ] 假设可证伪

## S1 文献与假设

- [ ] 检索协议已记录（来源 / 检索式 / 时间 / 筛选）
- [ ] 文献矩阵已建（作者 / 数据 / 方法 / 结论 / 关系 / 可引点）
- [ ] 每条假设有 ≥2 篇可核文献
- [ ] 所有引文可核（标题 / 作者 / 年份 / DOI）

## S2 数据获取

- [ ] 来源、期间、代码口径、字段、取数时间齐全
- [ ] 变量字典完成（定义 / 来源 / 计算 / 单位）
- [ ] 原始数据只读留存
- [ ] 已记录用了哪个来源或采集代码

## S3 数据清洗

- [ ] 剔金融业 / ST / IPO 当年已执行
- [ ] B 股 H 股按设计处理
- [ ] 关键变量缺失处理已说明
- [ ] 全样本统一缩尾（比例已记录）
- [ ] 面板检查（xtset / xtdescribe）完成
- [ ] 清洗日志已留痕

## S4 实证与稳健性

- [ ] 分析计划先于回归
- [ ] 基准回归 + 聚类层级说明
- [ ] ≥3 项稳健性检验
- [ ] 内生性处理与识别假设讨论
- [ ] 报告经济意义而不只统计显著

## S5 写作

- [ ] 引言含钩子 / 问题 / 发现 / 贡献 / 路线图
- [ ] 摘要最后写且 100-150 字
- [ ] 主张—证据对齐表无 missing

## S6 终稿与交付

- [ ] 引用逐条核验通过
- [ ] 文本六维度检查通过
- [ ] 参考文献格式统一
- [ ] 图表编号与交叉引用一致
- [ ] 分版本存档
