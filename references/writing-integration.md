# 写作集成：分阶段流程与作者声音

本文件说明论文写作阶段可以复用的本机写作能力。它们只影响表达和流程，不改变事实、数据、引用和研究结论。

## 分阶段写作（默认）

重任务论文默认接入 `staged-writing-workflow`：

1. 采访与事实确认；
2. 选题与大纲；
3. 文献检索；
4. 逐章撰写；
5. 引用核验；
6. 格式检查。

每阶段产出明确文件，用户确认后再进入下一阶段。任何阶段说“停”或“改”，立即停下。

## 自然化表达与 AIGC 标识边界

需要让长篇表达更自然、更具体、更保留作者判断时，参考 `article-writing` 的声音捕捉思路，但只采用表达层规则：

- 目标是自然、具体、像作者本人写的表达，不是伪造作者经历或规避事实核验；
- 任何产出都不得添加 AIGC 水印、AIGC 元数据标识或“AI生成”字样，除非用户另行明确要求；
- `article-writer` 的 AIGC 标识规则与用户要求冲突，因此不接入。

## 深度研究前置（可选）

论文写作前可以先走平台无关的深度研究流程，具体能力接口和降级路径见 [`research-integration.md`](research-integration.md)。它不是论文写作的硬依赖，也不要求用户安装某个特定 Agent。

1. 先收集用户自己的样文、笔记、发言或访谈；
2. 提取句长、节奏、修辞、语气容忍度和格式习惯；
3. 用这些特征调整表达，而不是套用固定模板；
4. 没有样文时，使用直接、具体、少夸张的默认风格，不假装掌握用户声音。

## 边界

- 不复制通用营销文案的标题党、金句和夸张句式到学术论文。
- 学术写作保留真实内容，不伪造作者经历、访谈或研究过程。
- `article-writer` 面向通用文章，且要求添加 AIGC 标识，与本 Skill 的默认边界冲突，不接入。
- 拟人化只改表达层；主张、证据、数据、引用和结论必须与前序阶段保持一致。
