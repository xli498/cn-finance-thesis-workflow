# 面板数据清洗细则（参考常见字段习惯的通用 SOP）

> 不同数据库的字段名、行业代码和样本定义可能不同，使用前必须按实际数据字典核对；本文件不代表任何数据库官方认证。

## 研究设计核对清单（非强制固定筛选顺序）

按研究问题、目标总体与数据字段逐项决定是否适用，并在样本构造说明中记录理由：

- 样本期与观测单位
- 行业范围及行业分类版本（金融业、房地产、类金融是否纳入）
- ST / *ST / PT 状态及处理窗口
- IPO / 上市年观测是否纳入
- B 股 / H 股与跨市场样本的范围
- 逐变量缺失值处理（删除、保留或有依据的插补）
- 异常值处理方法及阈值（可选缩尾；报告作用范围与稳健性）
- 唯一键、重复项、面板连续性 / 平衡度与处理规则
- 中间数据、变量字典和清洗日志的可复核性

## 常用表（以 CSMAR 命名为例）

- 个股日交易 / 月交易表
- 资产负债表 / 利润表 / 现金流量表
- 财务指标表（ROA / ROE / EPS）
- 公司基本信息表
- 公司治理年度表
- 市场收益率表

## 高频陷阱

- 行业排除范围未经论证，或忽略房地产 / 类金融样本对研究问题的影响
- 公司代码并非不可变 ID（借壳、退市需追踪）
- 季报不能直接相加，需年化口径一致
- 缩尾与样本划分的次序未预先规定，或不同分析样本的处理口径不一致且未说明
- CSRC 2001 与 2012 行业代码不可混用

## 收益率分布类风险指标（示例）

部分公司金融研究使用收益分布特征刻画风险，常见构造包括：

- 负收益偏态系数：对特质收益率做三阶矩标准化
- 收益上下波动比：比较上涨与下跌阶段的波动幅度

计算一般基于对市场收益率回归后的**残差**，须记录：

- 回归频率（周 / 日）
- 市场收益率口径（流通市值加权 / 等权）
- 最低观测数要求
- 年度内的观测窗口

不同口径结果差异较大，**必须在论文中写清构造过程**，且保持全文一致。
