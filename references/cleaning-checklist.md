# 面板数据清洗细则（参考常见字段习惯的通用 SOP）

> 不同数据库的字段名、行业代码和样本定义可能不同，使用前必须按实际数据字典核对；本文件不代表任何数据库官方认证。

## 标准筛选顺序

1. 样本期窗口
2. 剔金融业（按 CSRC 行业代码，2012 版 J / 2001 版 I）
3. 剔 ST / *ST / PT
4. 剔 IPO 当年观测
5. 视设计剔 B 股 / H 股
6. 关键变量缺失删除
7. 全样本统一缩尾 1%/99%
8. 面板检查与保存

## 常用表（以 CSMAR 命名为例）

- 个股日交易 / 月交易表
- 资产负债表 / 利润表 / 现金流量表
- 财务指标表（ROA / ROE / EPS）
- 公司基本信息表
- 公司治理年度表
- 市场收益率表

## 高频陷阱

- 剔金融业时忘记房地产 / 类金融（须在研究设计中说明）
- 公司代码并非不可变 ID（借壳、退市需追踪）
- 季报不能直接相加，需年化口径一致
- 缩尾必须全样本统一，子样本不二次缩尾
- CSRC 2001 与 2012 行业代码不可混用

## 收益率分布类风险指标（示例）

部分公司金融研究使用收益分布特征刻画风险，常见构造包括：

- 负收益偏态系数：对特质收益率做三阶矩标准化
- 收益上下波动比：比较上涨与下跌阶段的波动幅度

计算一般基于对市场收益率回归后的**残差**，须记录：

- 回归频率（周 / 日）
- 市场收益率口径（流通市值加权 / 等权）
- 最低观测数要求
- 年度内的观测窗口

不同口径结果差异较大，**必须在论文中写清构造过程**，且保持全文一致。
