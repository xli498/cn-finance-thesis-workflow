# 中文论文文本确定性检查（六维度）

> 这些是可按规则人工复核的检查项，不依赖模型判断；本目录不附带自动检查脚本。

## 可信度

- 模糊引用：「有学者指出」「研究表明」但无具体出处
- 未来年份引用
- 过度断言：「显然」「必然」「毫无疑问」附近无论据

## 术语

- 同一概念多译名混用

## 格式

- 空脚注 / 空参考文献条目
- 参考文献缺文献类型标识（[M] [J] [D]）
- 中英文标点混用
- 标题编号层级混用

## 语体

- 口语化（说白了、其实吧、笔者觉得）
- 自称不统一（本文 / 笔者 / 我们）

## 逻辑

- 连续断言无论证
- 并列堆砌无递进
- 引文后缺分析
- 因果前提未论证
- 总结句概念堆砌

## 结构

- 缺摘要 / 关键词 / 参考文献
- 引言缺论点句
