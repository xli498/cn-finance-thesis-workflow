# 中文实证论文写作规则

## 总则

- 读者优先：假设读者是忙、会略读、且不一定是你领域的同行。
- 作者参与式表达：先通过访谈或批注确认作者的研究动机、判断、术语偏好和真实研究过程，再据此组织文字；不要用统一模板替代作者思考。
- 人拟化不等于口语化：可以调整句式长短、段落节奏和衔接方式，但必须保留学术定义、证据边界、统计口径和引用规范。
- 具体来自真实研究：用作者实际做过的取数、清洗、分析和判断解释问题；不得伪造作者经历、访谈内容或个人研究过程；没有完成的步骤不得写成已完成。
- 针对性改写：发现重复表达后，优先重组论证顺序、补充真实证据或删除冗余，不做整篇同义词替换。
- 事实与观点分层：明确区分文献观点、作者判断、数据结果和推测性解释，并保留相应引用或限定语。
- 三角式：最重要信息放最前，不把结论藏到最后。
- 一条核心贡献；说不清贡献就是还没想清。
- 结果完成、复核并冻结后，具体优于抽象：用实际系数和经济幅度替代空泛表述；结果尚未产生时不得填入猜测值或占位数字。
- 每个词都要有用；删掉不加分的句子。
- 主动语态、现在时；引用他人用「XX（年份）发现」。

## 引言公式

1. 钩子（1-2 段）：为什么 Y 重要 / 反常 / 有争议 / 规模大
2. 研究问题（1 段）：用什么方法、什么数据检验什么，并给出主结果
3. 主要发现（2-3 段）：核心系数与经济意义、稳健性、扩展
4. 文献与增量（2-3 段）：只谈最相关的 5-10 篇，说明「已有—不足—本文」
5. 路线图（1 段）：定制化

## 摘要公式（最后写，按院校或目标期刊要求控制篇幅）

做了什么 → 怎么做（数据 + 识别策略）→ 发现什么（具体）→ 意味着什么

## 常见错误

- 埋没重点
- 旅行记式罗列
- 清嗓式铺垫
- 只有清单没有故事
